# DocVerify — Обнаружение поддельных документов на базе ИИ

Полноценный веб-сайт для проверки подлинности PDF-документов и изображений с использованием искусственного интеллекта.

## 🚀 Возможности

- **Реальный анализ PDF**: проверка метаданных, цифровых подписей, следов графических редакторов, JavaScript, целостности структуры
- **Анализ изображений**: извлечение EXIF-данных, проверка камеры, GPS, параметров съёмки, следов редактирования
- **SHA-256 хеширование**: уникальная идентификация каждого файла
- **История проверок**: все анализы сохраняются локально в браузере
- **Адаптивный дизайн**: работает на всех устройствах

## 🛠️ Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- pdfjs-dist (анализ PDF)
- exifr (анализ EXIF изображений)

## 📦 Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/ВАШ_ЛОГИН/docverify.git
cd docverify

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Сайт будет доступен по адресу http://localhost:3000

## 🌐 Автоматический деплой через GitHub Actions

Проект настроен для автоматического деплоя на GitHub Pages при каждом push в ветку `main`.

### Настройка GitHub Pages

1. **Перейдите в настройки репозитория**:
   - Откройте ваш репозиторий на GitHub
   - Перейдите в **Settings** → **Pages**

2. **Настройте источник**:
   - В разделе **Build and deployment** → **Source** выберите **GitHub Actions**

3. **Включите GitHub Pages** (если ещё не включены):
   - Убедитесь, что выбран источник **GitHub Actions**

### Как работает автоматический деплой

Файл `.github/workflows/deploy.yml` автоматически:
- Собирает проект при push в ветку `main`
- Загружает собранные файлы на GitHub Pages
- Деплоит сайт на `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

### Ручной запуск деплоя

Вы также можете запустить деплой вручную:
1. Перейдите в вкладку **Actions** в вашем репозитории
2. Выберите workflow **Deploy to GitHub Pages**
3. Нажмите **Run workflow** → **Run workflow**

## 🔧 Что проверяется

### PDF-документы
- ✅ Валидность заголовка PDF
- ✅ Метаданные (автор, создатель, производитель, даты)
- ✅ Наличие JavaScript (потенциальная угроза)
- ✅ Цифровые подписи
- ✅ Следы графических редакторов (Photoshop, GIMP и др.)
- ✅ Согласованность дат создания/модификации
- ✅ Целостность структуры (маркеры %%EOF)
- ✅ Извлечение текста

### Изображения
- ✅ EXIF-данные (камера, объектив, ПО)
- ✅ GPS-координаты
- ✅ Параметры съёмки (ISO, диафрагма, выдержка)
- ✅ Дата съёмки и модификации
- ✅ Следы графических редакторов
- ✅ Соответствие формата расширению

## 📊 Результаты анализа

После проверки вы получите:
- **Уровень риска**: низкий / средний / высокий
- **Процент уверенности**: от 0% до 100%
- **Детальный отчёт**: все проверки с описаниями
- **Аномалии и предупреждения**: список обнаруженных проблем
- **SHA-256 хеш**: уникальная подпись файла

## 🔒 Безопасность

- Все анализы выполняются **локально в браузере**
- Файлы **не отправляются на сервер**
- История хранится в **localStorage** вашего браузера
- Вы можете очистить историю в любой момент
