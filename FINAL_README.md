# 🎯 DocVerify — Финальная версия

## ✅ Что реализовано

### 🔒 Антифрод система
- **Панель метаданных**: автор, ПО, даты, GPS (для изображений)
- **Хеширование**: MD5 + SHA-256 для уникальной идентификации файлов
- **LSB-анализ**: детекция стеганографии через анализ наименее значимых битов
- **Флаги структурных аномалий PDF**:
  - Инкрементальные правки (xref таблицы)
  - Скрытые слои (OCG)
  - JavaScript и встроенные файлы
  - Аннотации, формы, ссылки
  - Встроенные изображения

### 🤖 Детекция ИИ
- **Вердикт по изображению**: подлинное / ИИ / неопределённо + confidence score
- **Heatmap областей**: визуализация подозрительных областей с цветовой кодировкой
- **Разбивка признаков**:
  - Шум (ELA - Error Level Analysis)
  - Частоты (анализ гистограммы)
  - LSB-анализ (стеганография)
  - AI классификация (MobileNet)
- **Детекция ИИ-текста**:
  - `ai_probability` — вероятность AI-генерации
  - `perplexity` — предсказуемость текста
  - `burstiness` — вариативность длины предложений
  - `top reasons` — основные признаки

### 🎨 Интерфейс
- **Каскадный вывод результатов**: структура → контент → ИИ
- **Превью файлов**: отображение изображений перед анализом
- **Время анализа**: отображение длительности проверки
- **Сводка анализа**: статистика проверок (пройдено/предупреждений/ошибок)
- **Экспорт отчёта**:
  - JSON — полный отчёт в машиночитаемом формате
  - PDF — print-friendly HTML с кнопкой печати
- **Дисклеймер**: предупреждение о вероятностном характере детекции
- **Анимированная статистика**: счётчики проверок на главной странице
- **Анимированные частицы**: декоративные элементы на фоне

## ⚠️ Дисклеймер

Данный инструмент предоставляет вероятностную оценку подлинности документов на основе алгоритмического анализа. Результаты не являются юридически значимым заключением и не могут использоваться как единственное основание для принятия важных решений. Для критически важных случаев рекомендуется дополнительная экспертиза квалифицированными специалистами.
